# 운동일지 (Workout Log PWA)

웨이트·필라테스/PT 드릴·유산소·호흡 과제·신체측정을 한 곳에 기록하는 개인용 운동일지 웹앱.
설치 없이 폰 브라우저에서 열고 **홈 화면에 추가**하면 앱처럼 동작하며, 오프라인에서도 사용 가능.

## 기능
- **📷 기구 사진으로 추가**: 운동 추가 → 사진 찍기 → Claude가 기구를 알아보고 운동 이름·부위·자세 포인트·유튜브 사용법 링크를 만들어 바로 추가 (기록 탭 설정에 본인 Claude API 키 필요, 키는 폰에만 저장되고 백업 파일에 포함되지 않음)
- **▶ 사용법 영상**: 모든 운동 카드에서 유튜브 사용법 검색으로 바로 이동
- **오늘**: 운동 추가 → 세트별 무게·횟수/초/분 입력, ✓ 누르면 휴식 타이머 자동 시작. 지난번 기록 표시, 최고기록 갱신 시 🏆 PR 표시
- **홀드 타이머**: 플랭크·네발기기 호버·호흡 같은 홀드 운동은 ▶ 누르면 3초 준비 후 카운트다운
- **기록**: 날짜별 운동 내역, 주간 운동 횟수, 설정(휴식 시간·알림음), JSON 백업/복원, CSV 내보내기
- **진척**: 운동별 추정 1RM(Epley)·최고 무게·볼륨/최장 버티기/유산소 시간 그래프
- **신체**: 체중·골격근량·체지방률·허리둘레 기록 및 그래프
- **PT과제**: 2026-10-27 PT 세션 과제 6개가 미리 등록됨. 날짜별 체크, 14일 달성 현황, 부위별 통증(손목·종아리 등)·컨디션 메모

## 실행
정적 파일만으로 동작합니다.
```
cd workout && python3 -m http.server 8000   # http://localhost:8000
```
폰에서 쓰려면 GitHub Pages·Netlify 등 HTTPS 정적 호스팅에 `workout/` 폴더를 올린 뒤, 폰 크롬에서 열고 메뉴 → "홈 화면에 추가".

## 데이터
모든 데이터는 해당 기기 브라우저(localStorage)에만 저장됩니다. 브라우저 데이터 삭제 시 사라지므로 **기록 탭 → 백업 내보내기**로 주기적으로 백업하세요.
