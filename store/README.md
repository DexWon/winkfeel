## 2. 데이터 보안(Data safety) 설문 답변

| 질문 | 답 |
|---|---|
| 앱이 사용자 데이터를 수집하거나 공유하나요? | **예** (아래 선택 기능 때문) |
| 수집 항목 | 사진 및 동영상 → **사진** |
| 수집 목적 | 앱 기능 |
| 공유 여부 | 예 — 이용자가 본인 API 키로 ‘AI 기구 인식’을 켰을 때만 Anthropic으로 전송 |
| 선택 사항인가요? | **예** (이용자가 선택) |
| 전송 중 암호화 | 예 (HTTPS) |
| 삭제 요청 방법 | 앱 데이터 삭제 / 앱 삭제 |
| 그 외 운동·건강 기록 | 기기에만 저장되고 외부로 전송되지 않으므로 ‘수집’에 해당하지 않음 |

> AI 기구 인식 기능을 아예 빼면 “데이터 수집 없음”으로 답할 수 있습니다. 원하시면 앱에서 이 기능을 숨긴 빌드로 바꿔 드립니다.

**콘텐츠 등급 설문**: 폭력·성적 내용·도박 등 모두 “아니요” → 전체이용가 예상
**대상 연령**: 만 18세 이상(또는 13세 이상) 선택 권장
**광고 포함 여부**: 아니요
**건강 앱 선언**: “건강·피트니스(운동 기록)” 선택, 의료기기 아님

## 3. 출시 순서 (덱스원 회사 계정)

1. **D-U-N-S 번호 발급** — 무료, 신청 후 보통 1~2주. (한국 신청처: 나이스디앤비)
2. **구글 플레이 콘솔 가입** — play.google.com/console, 조직 계정 선택, 등록비 $25, D-U-N-S 입력
3. **업로드 키를 GitHub에 등록** — 별도로 전달한 `upload-keystore` 파일과 안내문대로 4개 비밀값 입력
4. **앱 빌드** — GitHub → Actions → *Android build* → **Run workflow** → 완료되면 결과물(Artifacts)에서 `.aab` 내려받기
5. **콘솔에서 앱 만들기** — 앱 이름 ‘자기관리해요’, 무료, 앱
6. **Play 앱 서명 사용**(기본값) 상태로 **프로덕션 → 새 버전 만들기 → .aab 업로드**
7. 위 1·2번 문구와 이미지, 데이터 보안, 콘텐츠 등급 작성 → **검토 제출** (보통 며칠 걸림)

업데이트할 때는 4번에서 새 `.aab`를 만들어 6번처럼 올리면 됩니다. 버전 번호는 빌드할 때마다 자동으로 올라갑니다.
